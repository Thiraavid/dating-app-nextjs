# GlowUp Dating App – Next.js Demo

A responsive Next.js dating app demo with:

- Landing Page
- Authentication UI (Login / Signup)
- User Profile Management
- Swipe Interface
- Match System
- Chat Interface
- Filters and Search
- Navigation and Routing
- Admin Dashboard Overview
- User Management (Admin)
- Reports and Moderation
- Content Review Panel
- State Management with React Context
- Data Handling using Mock Data + Local Storage
- Responsive Design

## Tech Stack

- Next.js (App Router)
- TypeScript
- React Context API
- Local Storage for persistence
- Custom CSS

## How to run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`

## Main Routes

- `/` → Landing page
- `/auth` → Login / Signup
- `/discover` → Swipe UI
- `/matches` → Match list
- `/chat` → Chat interface
- `/profile` → Profile management
- `/admin` → Admin dashboard

## Notes

- This is a frontend demo using local state and browser local storage.
- No backend is required.
- You can later replace local storage functions with real APIs easily.
